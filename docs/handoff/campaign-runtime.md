# campaign-runtime

Обновлено: 2026-08-14 · ветка: main (последние правки — PR #95, #97, #98, #100, #101)

## Состояние

Цикл кампании: скрейп → фильтры → fit-гейт → walk по платформам → подача. Окно автоматизации
видимое (требование политики CWS — не предлагать headless), живое превью снимается скриншотами
через CDP.

**Капы слоёные и работают.** Серверная правда — `subscriptions.py`: MAX_PER_PLATFORM=15 вне тира,
дневной лимит по тиру (free 20 / pro 30 / tap 30 / admin ∞), free-taste 40 lifetime; считается из
БД, клиент не подделает. Реальный ban-гейт до клика — клиентский счётчик на входе каждой фазы
(8 точек) с SAFE-дефолтом 20 при сбое. На 429 кампания теперь останавливается (#95).

**Auto и Tap делят один движок подачи**, различаются входом и экономикой: auto = walk + ASSESS_FIT
(fail-closed, пороги 35/55/70) + Sonnet cover; tap = только пул одобренных свайпов, без fit-гейта
(свайп = решение человека) + Haiku cover. Капы применяются к обоим.

Radius и work-setting (Remote/Hybrid/On-site) доезжают до расширения через START-payload (#100/#101).

## Последний заход

- **Зомби-heartbeat (#98)** — корень: `/extension/ping` штамповал `last_ping_at` безусловно, а
  расширение пингует раз в минуту просто когда загружено. Heartbeat мерил живость **расширения,
  а не кампании** → TTL не истекал никогда, мёртвый прогон 2 дня показывал «Watch Live».
  Теперь heartbeat = только ping с `campaign_running: true`; idle-ping снимает флаг (поднять
  клиент не может), грейс 120с от `started_at`.
- Radius чинился дважды: #97 добавил *потребление* в расширении, а кормить было нечем —
  `search_radius_miles` не клался в `campaignFilters`. #100 добавил подачу.
- Терминальный skip вместо ре-queue: одна сложная форма больше не молотит очередь.

## Сломано / не доделано

- **Троттлинг фонового окна — главный нерешённый блокер.** `chrome.windows.create({focused:false})`
  (~background.js:1271) душит таймеры скрытого окна → 5-6 мин на форму. Отсюда вся хрупкость
  поллов и watchdog'ов. Цель <90с. Варианты: короткие окна фокуса (крадёт фокус у Игоря),
  offscreen/CDP-исполнение (CDP не троттлится — скриншоты уже так работают), уход с `setTimeout`
  на MutationObserver. **Риск высокий**: трогает рабочий пайплайн, до мержа нужна реальная подача
  на каждой из GH/Ashby/Lever с проверкой, что счётчик растёт и tap↔auto не сломан.
- Дрейф локального счётчика: при сбросе storage клиент может перебрать до 15 — каждая уходит
  работодателю, бэкенд только 429-ит save. Задокументировано в `background.js:241`.
- Манифест просит права на убранные из ростера платформы (glassdoor/monster/careerbuilder/dice/
  wellfound) — типовая придирка ревью CWS. Чистить только сквозной уборкой ext+backend+website.
