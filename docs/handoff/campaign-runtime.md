# campaign-runtime

Обновлено: 2026-09-11 · ветка: main · ext в проде: **1.8.3**

## Состояние

Цикл: скрейп → фильтры → fit-гейт → walk по платформам → подача. Окно автоматизации **видимое**
(политика CWS), превью через CDP. Auto и Tap делят один движок; капы слоёные — серверная правда
`app/db/subscriptions.py`, клиентский ban-гейт с SAFE-дефолтом 20, на 429 стоп (#95).

Паузы-с-передачей-человеку, все по одной схеме (строка в окне + лента + `DETECTION_TRIPPED` +
авто-возврат + стоп через 2 ч): капча (#72), логин-стена, **стена согласия «Accept Terms»
(#182)**. Разница: капча в pool-режиме СКИПАЕТ пик (вакансие-специфична), стена согласия
ПАУЗИТ и там (аккаунт-широкая); Accept не жмём никогда — юр-действие владельца.
Hand-off несёт `kind`/`action` — дашборд (website #146) и попап различают копию.
