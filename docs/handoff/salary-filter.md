## Состояние

**Зарплатный фильтр не применяется ни на одном живом пути.** Верифицировано 09-25 роем
`wf_849e0148-99d` (2/2 скептика по каждой точке), отчёт —
`docs/reviews/2026-09-25-verify-hypotheses.md`. Три дыры:

1. `app/routers/jobs.py:187` — `on_search_filter`, общий read-гейт **деки И auto-ATS-очереди**
   (зовут `get_ats_queue` ~235 и `get_deck` ~296). Применяет keyword/job_type/страну/локацию —
   salary в выражении отсутствует вовсе.
2. `app/routers/campaign.py:256` — `campaign_start` кладёт в `campaignFilters` только keywords,
   kw_cursor, platforms, location, job_type, radius. Поля зарплаты нет и в `CampaignStartRequest`
   (`app/schemas.py:82-86`). Indeed/ZR подаются **нативным обходом** (`background.js` ~898
   `pickNextStage` → `content.js` прямо из выдачи), пул они не проходят → **у нативного пути нет
   зарплатного гейта ни в одной точке**.
3. `app/routers/jobs.py:737` — `POST /jobs/ingest`, единственный вход Indeed/ZR в пул
   (`SERVER_SCRAPE_SKIP` ~110 запрещает серверный скрейп обоих), пишет карточки без
   `filter_by_salary`.

Что есть в наличии: `modules/salary_filter.py` (регексп по тексту, только фильтрует),
`profiles.salary_min/max` (префы юзера). Колонки salary в `jobs` НЕТ — память
`project_salary_not_stored`.

## Сломано / не доделано

- 🚧 **БЛОКЕР-РЕШЕНИЕ ИГОРЯ, без него фикс делать нельзя**: зарплата структурно не хранится и
  парсится регекспом из описания, то есть у БОЛЬШИНСТВА вакансий она `unknown`. Жёсткий гейт
  `unknown → reject` опустошит деку — это ровно та ошибка, которую уже разобрали с городом
  («ужесточать фильтр показа бессмысленно»). Варианты: (a) `unknown` пропускать, режектить
  только явно ниже вилки (консервативно, рекомендую); (b) `unknown` режектить (честно, но
  колода схлопнется — нужен замер fill-rate ПЕРЕД включением); (c) нативный Indeed/ZR отдать
  URL-параметру зарплаты вместо пост-фильтра.
- Замер не снят: сколько строк пула реально несут распознаваемую вилку. Делать ПЕРВЫМ — он и
  выбирает вариант выше.
- `jobs.py:757` (`describe_job` хранит текст с реальной платой, но никто не перепроверяет) —
  medium, скептиками НЕ проверялся.

## Следующий шаг

Снять fill-rate зарплаты по живому пулу (сколько строк дают распознаваемую вилку через
