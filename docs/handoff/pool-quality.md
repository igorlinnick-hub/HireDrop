# pool-quality — описание → балл → ранжирование → тейлоринг

Обновлено: 2026-09-15 · ветка: main

Одна цепочка: **чем наполняем пул → видит ли скорер описание → как ранжируем → за что
платим.** Все звенья ломались по одной причине: комментарий описывал намерение, а
читался как описание системы.

## Закрыто (разбор — в коммитах)

- **#192** — `_format_job` выбрасывал строку Description, когда её нет, и модель
  награждала отсутствие данных. 24 из 26 прошедших гейт были безописательные LinkedIn.
  A/B живьём: `6,8,6 → 5,5,5`.
- **#193** — харвест шлёт сниппет карточки; `/jobs/ingest` скорит от `MIN_SCORABLE_DESC=120`.
  ⚠️ сработал наполовину — см. ниже.
- **#194** — гейт тейлоринга снят (проходили 2 из 719), Workday убран в `WORKDAY_BOARDS_PARKED`.
- **#196** — кап `discover_ats` считал СОБРАННОЕ до дедупа → 71% скачанного выбрасывалось
  каждый прогон. Замер: доступно 560, возвращалось 160. Новых строк за 5 прогонов было
  `160·80·64·35·45`, стало `160·160·160·80·0` (ноль = вотчлист честно исчерпан).

## Живой прогон 09-15 22:41 UTC — прогнан сессией, без Игоря

Первый прогон через `scripts/e2e/` (sync → Reload extension → Start → 4 мин → Stop →
проверка). Кампания шла: `found` 775→778, `run-started` встал, подач 0.

**#193 сработал наполовину, и вторая половина — не «коротко», а «не то поле».** Описания
приезжают (2 строки из 3 против 0 из 31 до прогона), но в них метаданные карточки:

```
56 симв.  "$100,000 - $140,000 a yearFull-timeWeekends as needed +1"
34 симв.  "$90,000 - $110,000 a yearFull-time"
 0 симв.  ""
```

`MIN_SCORABLE_DESC=120` сработал как защита: `score` остался `null`, и это правильно —
опусти порог, и скорер оценивал бы вакансию по строке «$100,000 a yearFull-time», то есть
ровно баг #192. Чинить `extractCardInfo` в `content.js`, **не** порог и **не** скоринг.

`tailored_resume` остался непроверенным: подач в прогоне не было, тейлорить нечего.
