# pool-quality — описание → балл → ранжирование → тейлоринг

Обновлено: 2026-09-15 · ветка: main

Одна цепочка: **чем наполняем пул → видит ли скорер описание → как ранжируем → за что
платим.** Все три звена ломались по одной причине: комментарий описывал намерение, а
читался как описание системы.

- **#194** — гейт тейлоринга снят (рудимент: проходили 2 из 719; `fit_score` нигде не
  сохраняется, но у `resume/url/best` один вызывающий = «мы подаём»). Цена замерена:
  $0.0070/вызов, заявка $0.0129 → $0.0199. Workday убран из сбора в
  `WORKDAY_BOARDS_PARKED`, сторож — `tests/test_watchlist_platforms.py`.

## 🔁 Точки возврата — прогнать ПОСЛЕ первого живого прогона

```sql
select count(*) as indeed_24h,
       count(*) filter (where coalesce(description,'') <> '') as with_desc,
       count(score) as scored,
       round(avg(length(description)) filter (where coalesce(description,'')<>'')) as desc_len
from jobs where platform='indeed' and created_at > now() - interval '24 hours';
select count(tailored_resume) from jobs where created_at > now() - interval '24 hours';
```

- `with_desc = 0` → расширение не синкнуто/не перезагружено (грабли №1–2 в `CLAUDE.md`), **не** сервер.
- `desc_len < 80` → переехал селектор карточки, чинить `extractCardInfo`, а не скоринг.
- сниппеты в среднем ВЫШЕ полных описаний → #192 повторился, поднимать порог.
