# night-shift — серверный исполнитель ATS-подач (пока юзер спит)

Обновлено: 2026-10-01 · ветка: main (HireDrop #292)

## Состояние

`scripts/night_shift/executor.py` (Playwright headless) идёт по **той же очереди, что и
расширение** (`_ats_candidates` + `_prejudged_queue`: сохранённые вердикты, бар юзера, свежие
первыми, кап 2 заявки на компанию за 60 дней) и подаёт на Greenhouse и Ashby. `--max N` — сколько
заявок за запуск (по умолчанию 1); стоп — N отправлено, кап, либо **3 отказа сабмита всего**.
Dry-run по умолчанию, `--live` явный.

Ответы — через `common.answer()`: сначала то, что мы ЗНАЕМ (зарплата из
`profile.salary_expectation`, сайт, «откуда узнали» = карьерная страница компании, «живёте ли в
X» = сравнение с городом/штатом), потом общий ответчик в режиме `unattended`: вопрос про
обстоятельства человека, на который нет ответа ни в резюме, ни в профиле, возвращается пустым.
Пустое обязательное поле = **хендбэк** (строка в `handbacks` + activity с `outcome=`), а не
догадка. Хендбэком становится и любой неподтверждённый сабмит; открытый хендбэк ночью не
переоткрывается, нокаут уходит из пула.

Сухой проход по живой очереди Игоря 10-01: `14 форм → 4 готовы, 8 хендбэков, 2 нокаута`.
Готовы: DoorDash ×2, Tia, Hightouch — каждый ответ там из профиля или резюме.

## Последний заход (10-01)

- Проход превратился из «одна форма и стоп» в обход очереди; дедуп читается один раз и строго
  (живой прогон отказывается стартовать, если историю заявок прочитать не удалось).
- Ответчик **подписывал «я реальный человек, не бот/ИИ, заполнил лично»** (Muck Rack) и выбирал
  «I am a human being» (Grafana). Закрыто в общем `ai_question_answer` — то есть и для расширения.
- Выдуманное, что ехало работодателям: зарплата $55–85k при фильтре от $100k; «страна проживания
  → Afghanistan» (список из 250 стран, читались первые 40); «West Coast → Yes» из Гавайев;
  «узнал из LinkedIn»; подпись именем в текстовом поле; согласие на SMS. Всё закрыто правилами.
- Greenhouse: `Location (City)` и `School` — поля с поиском, печатаются из профиля; обратное
  чтение дропдауна не читало ничего (не тот контейнер) — починено и сравнивает на равенство.
- Рой-скептик воспроизвёл 16 дефектов первой версии; каждый закрыт тестом из его же случая
  (`tests/test_night_shift_walk.py` — симуляция обхода без браузера, проверена мутациями).

## Сломано / не доделано

- **Живой подачи с сервера всё ещё не было.** Классификатор auto mode запрещает сессии `--live`
  (10-01, дважды). Обойти нельзя и не нужно — команду запускает Игорь.
- Доля `428` не измерена ⇒ решение по прокси не принято. С ноутбука Игоря это будет число для
  ДОМАШНЕГО IP; для датацентра его даст только запуск на Railway.
- Чекбокс-группы Greenhouse («How did you hear», «Acknowledge» у Twilio) не заполняются → хендбэк.
- Подтверждения-уведомления («Applicant Privacy Acknowledgement», «I understand…») ночная смена
  по-прежнему отмечает сама. Подписи и аттестации — нет. Граница — решение Игоря.
- Ashby: в очереди один кандидат (Suno), живого отказа `flagged` так и не видели.
- Ext-лейну: `content.js` на клиенте отвечает Yes на «authorized to work in <любая страна>»;
  его opt-in-паттерн (`sms|opt.?in|newsletter`) отвечает No на «Have you managed SMS programs?».
- Автопереключение день↔ночь и Railway-воркер не начаты — после первой живой подачи.
