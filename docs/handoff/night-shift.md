# night-shift — серверный исполнитель ATS-подач (пока юзер спит)

Обновлено: 2026-09-26 · ветка: main

## Состояние

`scripts/night_shift/executor.py` (Playwright headless) подаёт на Greenhouse с сервера.
Цикл гейтов, в этом порядке (бесплатные и точные — до платного судьи): свежесть → живая
форма → локация → дедуп → fit → заполнение → нокаут → кап бэкенда → сабмит → запись как у
расширения. Dry-run по умолчанию, `--live` явный. Форма Amplitude заполняется целиком
(fit 72, письмо 700 знаков, ошибок нет) — сверено скриншотом.

**Живой подачи с сервера ещё не было ни одной.** Гард сессии блокирует `--live`, команду
выполняет Игорь.

Архитектура (разведка 09-23, рой + скептики) — две посылки оказались ложными:
- **Свой ATS-борд бесполезен**: GH и Ashby раздают ОДИН глобальный reCAPTCHA site-key на всех
  арендаторов, score арендатору не виден. Свой калибровочный ключ чужой score не предскажет.
- **Низкий score ≠ тихий дроп**: GH просит код из почты (**428**, `#security-input-0..7`).
  Провал видимый ⇒ метрику берём из ответа сабмита. Солвер отвергнут: проблема не в токене.

## Последний заход

- Аудит роем **до** первой партии: 6 подтверждённых находок, 4 критических — все закрыты
  (кап обходился через `service_role`, дедупа не было, комбобокс кликал не тот вариант,
  галочки пропускались, «форма исчезла» = отправлено без проверки статуса).
- P2-инструментовка: 4 исхода сабмита (`sent`/`invalid`/`captcha_code`/`unknown`), тег
  `outcome=` в ленте. Валидация проверяется ПЕРВОЙ — иначе свой баг травит метрику репутации.
- Письмо доставляется (перенос из ext со всеми граблями #248), генерация ленивая, текст
  перечитывается из поля перед записью.
- Локация и нокаут: пул — архив, фильтр применяется и при подаче; честный «нет» на жёсткое
  требование отменяет подачу.
- Дыра всего продукта: «Chile, Remote» читалось как подходящее (страны не было в `_NON_US_RE`).
  Список расширен, US-города с «заграничными» именами защищены, обе стороны в тестах.

## Сломано / не доделано

- **`work_setting` исполнителем не читается**, и в профиле Игоря он пустой. Правило: удалёнка —
  где угодно; гибрид/офис — только выбранная локация и радиус. Сейчас гейт судит по географии,
  значит офисная вакансия в своём городе пройдёт при желании работать только удалённо.
  Отдельно: на дашборде поле должно стать обязательным до старта кампании (правка сайта).
- Нокаут-гейт ни разу не отработал вживую — проверочный прогон упал раньше на
  «fit judge unavailable» (fail-closed сработал верно).
- Доля `428` не измерена ⇒ решение по резидентным прокси не принято. Покупать только после числа.
- Ashby-адаптера нет. Схема: `POST /api/non-user-graphql?op=ApiJobPosting` без авторизации;
  на странице `.ashby-application-form-field-entry[data-field-path=…]`. Часть оргов на старой капче.
  Пул-ссылки Ashby с задвоенным `/application/application` дают 404, базовый URL живой.
- Автопереключение день↔ночь (heartbeat мёртв ⇒ сервер заступает) не построено: запуск руками.
