# night-shift — серверный исполнитель ATS-подач (пока юзер спит)

Обновлено: 2026-10-01 · ветка: main (HireDrop #292; профильные поля — #293, см. `answers-at-signup.md`)

## Состояние

`scripts/night_shift/executor.py` (Playwright headless) идёт по **той же очереди, что расширение**
(`_ats_candidates` + `_prejudged_queue`: сохранённые вердикты, бар, свежие первыми, кап 2 на
компанию за 60 дней), Greenhouse и Ashby. `--max N` — заявок за запуск (дефолт 1); стоп: N
отправлено, кап, либо 3 отказа сабмита всего. Dry-run по умолчанию, `--live` явный.

Ответы — `common.answer()`: сначала то, что ЗНАЕМ (зарплата = `profile.salary_expectation`,
«откуда узнали» = карьерная страница, «живёте ли в X» = сравнение с городом/штатом, длинные
списки печатаются из профиля), потом общий ответчик в режиме `unattended` — вопрос про
обстоятельства человека без ответа в резюме/профиле возвращается пустым. Пустое обязательное
поле и любой неподтверждённый сабмит = **хендбэк** (строка `handbacks` + activity `outcome=`);
открытый хендбэк ночью не переоткрывается, нокаут уходит из пула.

Сухой проход по живой очереди Игоря 10-01: 14 форм → **4 готовы** (DoorDash ×2, Tia, Hightouch),
8 хендбэков, 2 нокаута.

## Последний заход (10-01)

- Ответчик **подписывал «я реальный человек, не бот/ИИ, заполнил лично»** (Muck Rack) и выбирал
  «I am a human being» (Grafana). Закрыто в общем `ai_question_answer` — и для расширения тоже.
- Ехало работодателям выдуманное: зарплата $55–85k при фильтре от $100k; «страна → Afghanistan»
  (250 стран, читались первые 40); «West Coast → Yes» из Гавайев; «узнал из LinkedIn»; подпись
  именем; согласие на SMS; «authorized to work in Canada → Yes». Всё закрыто правилами + тестами.
- Greenhouse: `Location (City)`/`School` — поля с поиском, печатаются из профиля; обратное
  чтение дропдауна не читало ничего (не тот контейнер), теперь сравнивает на равенство.
- Рой-скептик воспроизвёл 16 дефектов первой версии (в т.ч. две заявки при `--max 1`, дедуп
  fail-open); каждый закрыт тестом из его случая, `test_night_shift_walk.py` проверен мутациями.

## Сломано / не доделано

- **Живой подачи с сервера всё ещё не было**: классификатор auto mode запрещает сессии `--live`.
- Доля `428` не измерена. С ноутбука это число для домашнего IP; для датацентра — только Railway.
- Чекбокс-группы Greenhouse (Twilio) не заполняются → хендбэк. Ashby: в очереди один Suno.
- Уведомления («Privacy Acknowledgement», «I understand…») смена отмечает сама, подписи и
  аттестации — нет. Где граница — решение Игоря.
- Ext-лейну: `content.js` отвечает Yes на «authorized to work in <любая страна>»; его opt-in
  паттерн (`sms|opt.?in`) отвечает No на «Have you managed SMS programs?».
- Railway-воркер и автопереключение день↔ночь не начаты — после первой живой подачи.
