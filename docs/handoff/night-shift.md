# night-shift — серверный исполнитель ATS-подач (пока юзер спит)

Обновлено: 2026-09-27 · ветка: main

## Состояние

`scripts/night_shift/executor.py` (Playwright headless) подаёт на **Greenhouse и Ashby**
(`--platform greenhouse|ashby|all`, по умолчанию оба; Ashby — `ashby.py`, общие правила —
`common.py`). Гейты по порядку (дешёвые и точные — до платного судьи): отбор через
`on_search_filter` + `fresh_enough` (одно правило с колодой и авто-очередью) → живая
форма → локация → `work_setting` → дедуп → fit → заполнение → нокаут → кап бэкенда →
сабмит → запись как у расширения. Dry-run по умолчанию, `--live` явный.

- Greenhouse: форма Amplitude заполняется целиком (fit 72, письмо 700 знаков) — скриншот.
- Ashby: механика проверена на 3 живых формах (Vanta / Supabase / Found) с заглушкой
  вместо ИИ — все обязательные поля, EEO decline, Yes/No, автокомплит Location, без ложных
  нокаутов. **Настоящий dry-run не прогнан: у ключа Anthropic кончился баланс.**
- `work_setting`: remote-only ⇒ офис/гибрид в своём городе больше не проходит (правило в
  `modules/job_location.matches_work_setting`, действует и на колоду/очередь). `--live`
  отказывается при пустом `work_setting`. На дашборде поле обязательно до авто-Start
  (website #209); «Any setting» = явное `any`.

**Живой подачи с сервера ещё не было ни одной.** Гард сессии блокирует `--live`, команду
выполняет Игорь.

Архитектура (разведка 09-23, рой + скептики) — две посылки оказались ложными:
- **Свой ATS-борд бесполезен**: GH и Ashby раздают ОДИН глобальный reCAPTCHA site-key на всех
  арендаторов, score арендатору не виден. Свой калибровочный ключ чужой score не предскажет.
- **Низкий score ≠ тихий дроп**: GH просит код из почты (**428**, `#security-input-0..7`).
  Провал видимый ⇒ метрику берём из ответа сабмита. Солвер отвергнут: проблема не в токене.
