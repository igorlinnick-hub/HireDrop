## Следующий шаг — Drop-уточнитель (в работе: jade-owl, ветка `feat/drop-clarifier`)

**Одобрено Игорем** (его же идея, сессия plum-salmon 10-09 21:43Z/21:50Z; подтвердил jade-owl по
транскрипту; #416 слит 22:03Z). Правила: ≤2 вопроса в день (второй — только если на первый
ответили); только спорная зона (|оценка − планка| ≤ 15, текущая версия вердикта, статус new);
вопрос — фиксированный шаблон, без текста модели; пропуск бесплатен; категорию повторно не спрашиваем.

**Решения Игоря 10-09 (jade-owl, AskUserQuestion):**
- Вопрос Drop задаёт **текстом в чате** (шаблон), на вакансии в списке — **только значок** Drop.
  Человек отвечает своими словами, Drop переводит в оценку 0–10 / 👍👎 и **уточняет** карточкой.
- Где: **пузырь у Drop в углу** («Quick question?») → чат с вопросом. Дашборд не захламляем.
- 👍/высокая на отсечённую → Drop предлагает **«Подать на неё?»**, в очередь — только по нажатию.
- 👎/низкая → карточка **«Не показывать такие»**, «вернуть» в одном месте (Settings), истекает само.
- **Сдвиг личной планки — вторым шагом**: после 8+ ответов, ±10, виден в Settings, отмена кнопкой.
- Защита от тупика (обещана plum-salmon): скрытое не может съесть весь список — сработало → не
  применяем и говорим это.
- Отсев по названию снят (21:53Z) → «отсечённая» = судья поставил ниже планки.
- Ответы для ai-economics — **дополнительный сигнал, не условие** (у них свой
  `measure_judge_calibration.py`; 1–2 ответа в день не наполняются без юзера → [[honest-metrics]]).
- Судья НЕ называет человеку очки («38 fit») — Drop знает только сторону (в списке / отсекли).

**Порядок (каждый шаг в проде отдельно, ничего не врёт):**
1. Бэкенд: таблица `fit_clarifications`, выбор вакансии, `GET /buddy/clarify`, ответ через
   `/buddy/ask` + `clarify_id` → инструмент Drop `record_fit_answer`, отчёт точности для ai-economics.
2. Сайт: пузырь, вопрос в чате, ответ с `clarify_id`, значок на вакансии в списке.
3. Действия: `fit_hidden` + «подать на неё» в `build_queue`, Indeed-батче и живом судье; защита от
   тупика; карточки Drop; Settings «Hidden by you».

155 за 4 дня; у precise (70) — 0 из 491. Вопросов хватит; у precise Drop просто молчит.

катить раньше сайта.

- **`lib/buddy.ts`**:
  - Добавить обработку `{"type":"proposal","proposal":{id, kind, title, lines[], confirm,
    steps[], navigate, note, done}}` → `on.onProposal(card)`.
  - `done` и `error` теперь несут `turn_id` — сохранять его в сообщении Drop.
  - В тело запроса добавить `cards: true`, как только карточки рисуются. Без этого флага Drop
    не получает `propose_action` и, как раньше, говорит, куда нажать. Так бэкенд безопасно
    катить раньше сайта.
  - Когда PDF загружен из чата — добавить `attachment: "resume_pdf"`.
  - Мелкая ошибка: после цикла не разбирается последняя строка без `\n`. Буфер стоит дочитать.
- **Карточка в `BuddyPanel`**: заголовок, `lines`, `note`, кнопка `confirm` и «Not now».
  - Нажатие выполняет `steps` ПО ПОРЯДКУ: `{method, path, body}` к `/api/v1` с Bearer.
