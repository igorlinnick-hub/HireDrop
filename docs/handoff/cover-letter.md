# cover-letter — письмо: когда пишется и куда доезжает

Форма-филлер целиком — соседний `ats-form-filler.md`.

## Состояние

**Письмо пишется, только когда форма его просит.** Единственная точка генерации —
`ensureCoverLetter()` (`content.js`), зовётся У ПОЛЯ. Нет поля → нет вызова модели, нет
строки в `applications`, History пишет «работодатель не просил письма» (website #198).
Текст привязан к вакансии ключом `coverLetterFor` — холодный контекст (#238) не подставит
письмо предыдущей. Скринер больше не отвечает на лейбл cover letter ИИ (была вторая оплата).

**Откуда всё** (`scripts/measure_letter_delivery.py`, 09-23): письмо писалось на КАЖДОЙ
заявке (103 из 107 строк), а в форму попадало 1 раз из 274 шагов. Инструмент считает:
сгенерировано / реально напечатано (`filled=[…cover…]`) / какие модули показывал Indeed.

**Где поле есть — по замеру:** Indeed не просит вовсе (0 за 243 загрузки формы);
Greenhouse просит в 267 из 320 схем (`data/gh_form_schemas.jsonl`), обязательным в 7;
Lever по-разному — на живой форме gopuff (09-25) поля нет вообще, и лог «no cover-letter
field» там ЧЕСТЕН.
