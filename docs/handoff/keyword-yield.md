# keyword-yield — пустой ключ поиска виден юзеру и не жжёт прогон

Сессия: plum-salmon · лейн keyword-yield · цель: цена и время прогона растут с заявками, а не с числом ключей; пустой ключ виден, без тупиков для юзера

Обновлено: 2026-10-09 (поздно) · ветка: main (#416 смержен, Railway `2e1dd82`)

## Зачем (решение Игоря 10-09)
Контрольный прогон 10-09: ключ «project manager» в San Diego = почти одна стройка, ~20 отказов судьи
за 25 мин, страница «0 fit you, 14 don't» судилась 82 с. Юзер с 20 ключами не должен платить
ни временем, ни непониманием. Деньги тут вторичны: прорабов решает Haiku (≈0.28¢), это ~0.6¢/заявку
из 4.9¢. **Отсев по названию снят с плана** (экономит мало, рискует ложными отказами).
Деньги — спорная зона судьи (Sonnet на 40–70: $0.22 из $0.44 прогона) → лейн ai-economics.

## Правила без тупиков (согласованы с Игорем)
- Ключ никогда не выключается насовсем: «пустой» = пропускается до конца ЭТОГО прогона, первая
  страница каждый прогон всё равно идёт. Последний живой ключ не пропускается никогда.
- Пусто = ≥2 страниц И ≥20 вердиктов И 0 подошедших за 7 дней. Неизвестно ≠ пусто.
- Отпечаток = резюме + режим + город. Новое резюме — всё с нуля. Замена одного ключа не трогает другие.
- Всё, что мы «не показываем», видно юзеру, отменяется одной кнопкой и истекает само.
- Все пустые → дашборд говорит это вслух (`all_dry`), а не молча показывает тихую кампанию.

## Контракты соседним лейнам
**ext-лейн (content.js / background.js — НЕ трогать отсюда):**
1. `PREJUDGE_CARDS` → `apiPost("/tools/assess-fit-batch", { jobs, keyword })`, где keyword —
   текущая фраза (`keywordList()[kwIndex]`, как в `currentKeywordKey`).
2. Ответ `keyword_yield.dry === true` → добавить текущий `kwIndex` в `kwDone` на этот прогон,
   ЕСЛИ после этого остаётся хотя бы одна живая фраза; строка в ленту:
   `⏭️ "<фраза>": 0 of <judged> fit in <pages> pages — skipping it this run`.
3. Нет поля / null → поведение как сейчас.

**сайт (jobflow-website, дашборд):** плашка у списка ключей по `GET /jobs/keyword-yield`:
«“project manager”: 0 из 28 подошли. Заменить на: [вариант] [вариант] [оставить]». Варианты —
под резюме (есть `role_suggest`). При `all_dry` — явное «ни один ключ не дал подходящих» + варианты.
«Оставить» — пока только скрыть плашку на 30 дней (локально); серверный флаг — следующим шагом.

**Drop (лейн drop-actions):** уточнитель 👍/👎 и 0–10. До 1–2 вопросов в день, только пограничные
вакансии (оценка у планки юзера или 👍 на отсечённое), шаблоны без свободного текста модели,
пропуск бесплатен, одну категорию повторно не спрашивать. Ответы → поправка планки юзера и замер
точности спорной зоны (нужен ai-economics перед сужением зоны Sonnet).

**ai-economics:** прогон 10-09 20:11–20:36Z: $0.44 / 9 заявок = 4.9¢; fit_judge Sonnet 29 вызовов
$0.221 (≈0.76¢/вызов), Haiku 37 / $0.103 (≈0.28¢), screener 13 / $0.078, job_score 19 / $0.035.
Рычаг к потолку 3–4¢ — ширина `FIT_CASCADE_BAND` (сейчас 15) или модель спорной зоны.
