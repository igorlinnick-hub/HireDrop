# keyword-yield — пустой ключ поиска виден юзеру и не жжёт прогон

Сессия: coral-merlin · лейн keyword-yield · цель: цена ИИ растёт с заявками, а не с ключами: урожайность ключей + дешёвый отсев по названию + потолок $/заявку, без тупиков для юзера; в проде с замером ai_calls до/после · шаг: Indeed-прогон закончен 07:45Z, Chrome свободен; разбор итогов · доска: `python3 scripts/sessions.py board`

Обновлено: 2026-10-10 · ветка: main (всё в проде: бэкенд #416/#418, ext 1.8.47 #419, сайт web #333)

## Состояние
- Сервер считает урожайность по фразе: `keyword_yield` (куски одной страницы склеиваются по
  page_key), `GET /jobs/keyword-yield` → {keywords, window_days, all_dry} по фразам ПРОФИЛЯ.
- Пусто = ≥2 страниц И ≥20 вердиктов И 0 подошедших за 7 дней. Ext пропускает пустую фразу до
  конца прогона (последнюю живую не трогает); ключ не выключается насовсем.
- Сайт (e94b64c): за пустым чипом в строке поиска мигает мини-чип `→ роль ×` (роль из
  `/tools/suggest-roles` раз за визит, в регистре ключа; урожайность перечитывается через 1.5 с
  после правки). Клик = замена ключа, × = оставить (30 дней, localStorage). Без текста — так
  решил Игорь, две словесные версии (пилюля со счётчиком, блок «→ [Swap] Keep») отвергнуты.
- Живой прогон 10-10 07:30–07:45Z (Indeed, broad, San Diego): строки пишутся верно —
  marketing manager 4/5, social media manager 5/6, marketing coordinator 5/5 (по 1 стр.),
  project manager 1/25 за 3 стр. Пустых нет → чипа нет, ext ничего не пропускал. 4 заявки.

## Последний заход
- Плашка → мини-чип; ревью агентом до мержа: роли были без кэша (Haiku, кап 20/день) и
  урожайность на каждое нажатие — починено (33b02a5) и проверено стендом со счётчиком вызовов.
- Прогон кончился сам на 14-й мин: «all keywords searched». Причина не баг лейна: фразы
  профиля уже потратили дневной слайс (floor(20/7)=2, тот же гавайский день, что утренний прогон),
  а project manager выбрал бюджет страниц (4).

## Сломано / не доделано
- Порог «0 подошедших» слишком строгий: project manager 1/25 (4%) не пустой, и на него ушло
  ~60% вердиктов прогона. Цена прогона $0.45 / 4 заявки = 11.3¢ (10-09: 4.9¢); судья $0.43 из них.
- Роли, добавленные сервером на старте (broad = 7 ролей из резюме), в профиль не попадают →
  чипа на них не бывает (ext пустые всё равно пропускает). Сознательно, не трогать без Игоря.
- «Оставить» только в браузере; all_dry словами не проговаривается.
