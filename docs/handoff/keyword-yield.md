# keyword-yield — пустой ключ поиска виден юзеру и не жжёт прогон

Сессия: coral-merlin · лейн keyword-yield · цель: цена и время прогона растут с заявками, а не с числом ключей; пустой ключ виден, без тупиков для юзера

Обновлено: 2026-10-09 (ночь) · ветка: main (бэкенд/ext в проде) + web `feat/keyword-yield-plaque` (#333)

## Состояние
- Прод: таблица `keyword_yield` (RLS без политик), `/tools/assess-fit-batch` принимает `keyword`+`page`
  и отвечает `keyword_yield` {keyword, pages, judged, fits, dry}; `GET /jobs/keyword-yield` →
  {keywords, window_days, all_dry} (#416, #418). Ext 1.8.47 шлёт keyword+page и пропускает пустой
  ключ до конца прогона, последний живой не трогает (#419).
- Правила (согласованы с Игорем): пусто = ≥2 страниц И ≥20 вердиктов И 0 подошедших за 7 дней;
  неизвестно ≠ пусто; ключ не выключается насовсем; отпечаток = резюме + режим + город.
- Сайт, web #333 (НЕ смержен): в строке поиска сразу за пустым чипом стоит мини-чип
  `→ Digital Marketing Manager ×`: ink днём, фиолетовый ночью, мигает кольцом `hd-dock-pulse`.
  Клик по роли = замена ключа; × = оставить ключ, чип скрыт на 30 дней (localStorage). Текста нет,
  причина только в aria-label. Одна роль на ключ, без повторов, роль берётся из `/tools/suggest-roles`.
- Почему так: Игорь отверг обе прежние версии: пилюлю с «0 of 28 fit in 7 days · Try A B» и
  отдельный блок «старый → новый [Swap] Keep» («отдельный пласт, длинно»). Не возвращаться к ним.

## Сломано / не доделано
- `all_dry` сайт больше не проговаривает словами: при всех пустых просто мигают все чипы
  (Игорь просил без объяснений). Нет ролей из резюме → чипа нет совсем.
- «Оставить» живёт только в браузере; серверного флага нет.
- Нет живой проверки на проде: строки `keyword_yield` от реального прогона ещё не смотрели.
