## ⚠️ CRITICAL TOOLING NUANCES (these cost the last session hours — don't repeat)

1. **osascript JS-read into Chrome needs "Allow JavaScript from Apple Events" ON** (Chrome menu → View → Developer). It **RESETS on every Chrome restart** — so DON'T restart Chrome to reload the extension.
2. **Reloading the extension does NOT re-inject content scripts into already-open tabs.** After a reload you MUST also **reload the tab** (dashboard F5, close old job-site tabs) — else you test against an ORPHANED script. `"Uncaught Error: Extension context invalidated"` in chrome://extensions → Errors is a **benign orphan**, not a code bug. Most "stale code" confusion last session was this.
3. **Reliable reload = chrome://extensions → HireDrop → toggle Disable→Enable → then F5 the dashboard tab.** MV3 service workers can run stale code otherwise (this is why the app count was moved OUT of the SW into content.js).
4. **There are TWO Chromes:** Igor's real Chrome (extension + campaigns) AND a Playwright-MCP Chrome (`ms-playwright-mcp` profile). osascript targets the real one. **Never run Playwright against a live campaign** — it drives the same real Chrome and steals the tab, killing the campaign. Playwright is fine for inspecting PUBLIC pages (Greenhouse/Lever forms) when no campaign runs.
5. **NEVER probe job BOARDS (Playwright/curl) from Igor's IP** — it flagged his home IP (Glassdoor/Wellfound block pages). ATS hosts (greenhouse/lever) are OK. Prefer the extension's own `FORM DIAG`/`APPLY DIAG` self-report logs over external probing.
6. **The 50-line activity_log ring buffer rotates fast when a ZR campaign runs** (it floods). To read platform-specific logs cleanly, STOP the ZR campaign first. DIAG lines also `logBackend` (durable) as of this session.
7. **Bridges (ping.js on hiredrop.io):** `HIREDROP_GET_PLATFORM_CONNECTIONS` (reads storage directly, not via SW), `HIREDROP_MARK_APPLIED` (seed dedup), `HIREDROP_SET_REVIEW` (review mode), `HIREDROP_READ_STORAGE`, `HIREDROP_PING/PONG`, `HIREDROP_START/STOP_CAMPAIGN`. All require a FRESHLY-RELOADED dashboard tab to have the latest ping.js.
